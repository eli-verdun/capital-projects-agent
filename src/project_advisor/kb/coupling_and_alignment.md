# Coupling And Alignment

Synthetic Meridian Project Delivery Advisor demo, snapshot 2026-10-29.

The synthetic CP-2500-4417 compressor package uses flexible disc coupling PN-4938966. Repeated waivers of the hot-alignment check hold point can leave misalignment that shows only at full load, even when a low-load recycle run is normal. Low vibration at slow roll after a trip is not proof the package is fit to restart. Alignment work and re-test need the approved inspection and test plan and an authorized package engineer.
